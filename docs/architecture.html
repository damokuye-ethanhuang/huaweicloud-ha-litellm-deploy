LiteLLM 私有化网关 · 华为云架构

CCE + overlay_l2 容器隧道 + Ingress 自动创建内网 ELB + RDS/DCS 主备。除堡垒机 EIP 外无公网入口。

请求链路

  1. 调用方（VPC 内或对等连接）访问 https://<ELB VIP>/v1/chat/completions，带 virtual key。公网无路径。
  2. ELB 由 CCE Ingress 控制器按 kubernetes.io/elb.autocreate 创建：独享型、type: inner、L7，VIP 落在 access。
  3. Ingress → Service（ClusterIP）→ 三个节点上的 pod 之一，按 /health/readiness 剔除故障副本。
  4. 鉴权与用量元数据来自 PostgreSQL；限流计数与缓存来自 Redis。
  5. 路由按 deploy-inputs.yaml 的 models[] 生成，主备模型互为 fallback。
  6. 出方向走 ModelArts VPCEP 或 NAT（默认不建 NAT，纯内网已验证可用）。

两个必须记住的约束

  • 隧道网络下 pod IP 不可路由。Pod 访问 RDS/Redis 时源地址被节点 SNAT 成节点地址，所以 data 只放行 app；放行 pod_cidr 是无效规则。
  • 三段地址不能重叠。VPC 10.0.0.0/22、容器 172.16.0.0/16、Service 10.247.0.0/16。重叠不会在建集群时报错，而是在 Pod 连不上数据库时才暴露。

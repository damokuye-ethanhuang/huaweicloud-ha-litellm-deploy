# LiteLLM 华为云部署技能 (litellm-huaweicloud-deploy)

> 当用户需要在华为云上部署 LiteLLM 代理、配置 AI 模型路由、或管理 LiteLLM 生产环境时使用本技能。
> 覆盖：CCE 部署、RDS+DCS 配置、Helm Chart、LTS/AOM 监控、CodeArts CI/CD、KMS/DEW 加密、安全规划、运维 Runbook。
> 架构原则：纯内网，不对公网提供服务。

## 触发条件

- 用户提到"部署 LiteLLM"、"LiteLLM 华为云"、"LiteLLM CCE"
- 用户提到"AI 模型网关"、"LLM Proxy"、"模型路由"
- 用户提到"GLM MaaS 部署"、"DeepSeek 模型代理"
- 用户提到本技能目录下的任何文件

## 前置条件

1. 华为云账号，已开通 CCE / RDS / DCS / ELB / KMS / LTS / AOM 服务
2. kubectl + helm 已安装并配置 CCE 集群连接（内网访问）
3. 已完成 `sa-checklist/security-planning-checklist.md` 中的必选项
4. VPC 纯内网规划完成（无 EIP / 无 NAT / 无公网路由）
5. VPC Endpoint 已创建（MaaS API 内网访问）
6. KMS CMK 已创建，RDS/DCS 磁盘加密已关联
7. RDS for PostgreSQL（主备+只读）已创建
8. DCS Redis（主备）已创建
9. 模型后端就绪：华为云 MaaS API Key 或 ModelArts 自建推理服务

## 部署步骤

### Step 1: 填写参数导入表
```bash
# 打开参数导入表，填写所有 ✅必填 字段
# 模型配置（第八节）支持任意数量模型，按需添加
cat deploy-input.md
```

### Step 2: SA 规划检查
```bash
# 打开解决方案架构师规划检查清单，逐项核对
cat sa-checklist/security-planning-checklist.md
```
确保所有 `[必选]` 项已 ✅，特别是纯内网相关项（无 EIP / 无 NAT / VPC Endpoint）。

### Step 3: 获取部署包
```bash
git clone https://<your-repo>/litellm-huaweicloud-deploy.git
cd litellm-huaweicloud-deploy
# 详见 deploy-guide.md Step 0
```

### Step 4: 准备基础设施
```bash
# 方式A: Terraform 一键创建（推荐）
cd infrastructure/terraform
terraform init && terraform plan && terraform apply

# 方式B: 参考指南手动创建
# - infrastructure/cce-cluster-guide.md  (CCE 3节点集群)
# - database/rds-setup-guide.md         (RDS 1主1备1读，KMS加密)
# - infrastructure/dcs-setup-guide.md   (DCS Redis主备，SSL加密)

# 创建 VPC Endpoint（MaaS API 内网访问）
# 华为云控制台 → VPC Endpoint → 创建终端节点 → 选择 modelarts-maas 服务
```

### Step 5: 数据库初始化
```bash
# LiteLLM 启动时 Prisma 自动建表
# 如需手动初始化（审计/备用）:
psql -h <rds-inner-ip> -U litellm -d litellm -f database/init-schema.sql
```

### Step 6: Helm 部署（纯内网）
```bash
# 开发环境
helm install litellm ./helm -f helm/values-dev.yaml \
  --set secrets.masterKey=sk-master-xxx \
  --set secrets.saltKey=sk-salt-xxx \
  # ... 其他 Secret

# 生产环境
helm install litellm ./helm -f helm/values-prod.yaml \
  --set secrets.masterKey=sk-master-xxx \
  --set secrets.saltKey=sk-salt-xxx \
  --set secrets.hwMassApiKey=sk-maas-xxx \
  --set litellm.models.glm.apiBase=https://<vpc-endpoint-maas-ip>/v2/ \
  --set secrets.deepseekApiBase=http://192.168.x.x:8000/v1/ \
  --set secrets.deepseekApiKey=xxx \
  --set secrets.databaseUrl=postgresql://litellm:pwd@192.168.x.x:5432/litellm \
  --set secrets.redisHost=192.168.x.x \
  --set secrets.redisPassword=xxx \
  --set secrets.uiPassword=strong-admin-pwd
```

### Step 7: 验证部署
```bash
kubectl get pods -n litellm
kubectl logs -n litellm -l app=litellm --tail=50
curl http://<内网elb-ip>/health/liveness
```

### Step 8: 配置监控（LTS/AOM + 本机 Grafana）
```bash
# 1. LTS 日志采集（控制台配置）
#    CCE → 日志 → LTS 日志组 → 结构化采集 LiteLLM stdout

# 2. AOM 指标采集（CCE 已自动接入 AOM）
#    自定义指标: LiteLLM /metrics 端点 → AOM

# 3. AOM 告警规则（参考 monitoring/alerting-rules.yaml）
#    AOM 控制台 → 告警规则 → 导入或手动配置

# 4. SMN 通知主题
#    SMN → 创建主题 → 订阅（短信/邮件/钉钉）

# 5. 本机 Grafana 看板
#    安装 Grafana → 配置 AOM/LTS 数据源（参考 monitoring/grafana-datasource-setup.md）
#    → 导入 monitoring/grafana-dashboard.json
```

### Step 9: 创建虚拟 Key
```bash
# 参考 runbooks/virtual-key-management.md
# Virtual Key 仅用于模型权限隔离，不含计费配额管理
curl -X POST http://<内网endpoint>/key/generate \
  -H "Authorization: Bearer <master-key>" \
  -H "Content-Type: application/json" \
  -d '{"key_alias": "app-prod", "models": ["glm-5.3", "smart-router"]}'
```

## 升级流程

当目标版本 > `version-preset.yaml` 中的当前预设版本时，执行 `runbooks/upgrade-guide.md`：

```bash
# 1. 检查版本差异
cat version-preset.yaml | grep -A2 "current:"

# 2. 如需升级，按 upgrade-guide.md 执行完整流程:
#    Release Notes → 兼容性检查 → 更新方案文件 → 测试验证 → 生产升级 → 更新预设
cat runbooks/upgrade-guide.md
```

> ⚠️ 升级不是只改镜像 tag，需重新走一遍部署方案更新流程（含文档、Helm、配置、验证）。

## 关键参数

| 参数 | 默认值 | 说明 |
|------|--------|------|
| LiteLLM 版本 | 1.100.3 | 镜像 ghcr.io/berriai/litellm:1.100.3（见 version-preset.yaml） |
| 副本数 | 3 | 跨AZ Pod反亲和 |
| 主模型 | GLM 5.3 | 华为云 MaaS（VPC Endpoint 内网访问） |
| 备用模型 | DeepSeek V4.1 FLASH | ModelArts 自建（同 VPC 内网） |
| 数据库 | RDS for PostgreSQL | 1主1备1读，KMS 磁盘加密 |
| 缓存 | DCS Redis | 主备跨AZ，SSL 加密 |
| 加密 | KMS + DEW | KMS 磁盘加密 + DEW 凭据托管 |
| 监控 | LTS + AOM | 日志→LTS，指标→AOM，看板→本机 Grafana |
| CI/CD | CodeArts | 华为云流水线 |
| HPA | 3-10 副本 | CPU 70% + Memory 80% |
| PDB | minAvailable: 2 | 滚动更新零停机 |
| 架构 | 纯内网 | 无 EIP / 无 NAT / 无公网路由 |
| Key 计费配额 | 不启用 | Virtual Key 仅用于模型权限隔离 |

## 注意事项

- `LITELLM_SALT_KEY` 一旦设置**永不可改**，否则已加密的模型凭证无法解密
- 客户端**永远使用 Virtual Key**，不使用 Master Key
- **纯内网架构**：无 EIP / 无 NAT / 无公网路由，MaaS API 通过 VPC Endpoint 内网访问
- **KMS/DEW**：RDS/DCS 磁盘加密使用 KMS CMK，密钥通过 DEW 凭据管理托管
- **监控**：日志持久化到 LTS，指标持久化到 AOM，Grafana 在本机部署
- **CI/CD**：使用华为云 CodeArts 流水线，非 GitHub Actions / GitLab CI
- **Key 管理**：暂不启用 LiteLLM 的 Key 计费和配额管理（budgeting 已关闭）
- 生产部署前必须完成 `sa-checklist/` 中所有必选项
- 旧 `scenario-b-cce-k8s/` 中的裸 YAML 已被 `helm/` 取代，保留作参考
